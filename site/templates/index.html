Self-hosted file server

Your files on your server, with the Nextcloud apps you already know.

Rostdav is a lean file server written in Rust. It speaks WebDAV and the parts of the Nextcloud protocol the official apps need: sign in, sync, share, restore. One program, one data folder, no PHP, no extra database server.

Install Rostdav Read the user manual

Free and open source · Apache-2.0 or MIT · Linux x86-64 and arm64

What you get

  • Works with the Nextcloud apps

    Sign in from the Android app, the desktop client or the iOS app with Login Flow v2. Every device gets its own app password that you can revoke.

  • Sharing that you control

    Share with other users or by public link, with a password, an expiry date and view, edit or upload-only access.

  • Versions and a trash bin

    Overwritten files keep their older versions; deleted files wait in the trash. Both have limits you set, so the disk does not fill up unnoticed.

  • A web interface that matches

    Browse, upload folders by drag and drop, share, restore, and administer. Light and dark, English and German, works on a phone.

  • Small and safe by design

    One binary, Argon2id passwords, hashed tokens, optional two-factor sign-in, an event log and a consistency check.

  • Honest about compatibility

    Every compatibility claim names its source: a recording of Nextcloud 35, the client code, or a real app. See what was tested.

Try it in two minutes

docker run -d --name rostdav -p 127.0.0.1:8080:8080 -v rostdav-data:/data ghcr.io/pierrejochem/rostdav:latest
read -rs -p 'Password for alice: ' PW; echo
printf '%s\n' "$PW" | docker exec -i rostdav rostdav admin user add alice --admin

Then open http://127.0.0.1:8080 and sign in. For real use put a reverse proxy with HTTPS in front: the installation guide has a ready Compose file.
