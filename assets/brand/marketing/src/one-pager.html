rostdav
v0.7
Your files.
Your server.
One small program.
A lean, self-hosted file server in Rust with WebDAV that works with the official Nextcloud apps.
Works with Nextcloud apps
Android app and desktop sync client, Login Flow v2, chunked upload, favorites.
Versions, trash, shares
Restore older versions and deleted files; public links and user shares.
Search
By name and by the text of files, over everything you can reach.
Web interface
Light and dark, English and German, administration, optional two-factor.
Operations
Event log, consistency check, maintenance mode, backup and restore from the CLI.
Open source
Apache-2.0 or MIT. Linux x86-64 and arm64, as a binary or container image.
Start in a minute
cargo run -p rostdav -- serve
curl http://127.0.0.1:8080/healthz
