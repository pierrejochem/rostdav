# Rostdav brand guidelines

Rostdav is a lean, self-hosted file server. The brand should feel the same way: small, solid, honest, a little warm. Rust-orange on iron, no decoration that does not carry meaning.

## Positioning

**One line:** A lean, self-hosted file server in Rust with WebDAV that works with the official Nextcloud apps.

**Tagline (primary):** Your files. Your server. One small program.

**Alternates:** No PHP. No web stack. Just your files. / One binary. One folder. / Mistakes are undoable.

**Audience:** people who run their own server (homelab, small teams, privacy-minded users) and already use or want the Nextcloud mobile and desktop apps, without running the full Nextcloud stack.

**Proof points (use only these; each is documented in the README and docs/compatibility.md):**
- One program, one data folder. No PHP, no web server stack, no separate database server.
- Works with the official Nextcloud Android app and the desktop sync engine (Login Flow v2, app passwords).
- Versions, trash, shares and public links; search by name and by file text.
- Web interface in light and dark, English and German, with administration and optional two-factor sign-in.
- Linux x86-64 and arm64, as a binary or container image. Apache-2.0 or MIT.

**Never claim:** that Rostdav is a Nextcloud product or replaces all Nextcloud apps and features; support for the iOS client or desktop GUI (not tested); performance or security numbers that are not measured in the repository. Always keep the disclaimer when space allows: "Not a Nextcloud product; not affiliated with Nextcloud GmbH."

## Voice

Plain, specific, calm. Short sentences. Say what it does and what it does not do.

- Do: "No PHP, no web server stack, no separate database server."
- Don't: "Revolutionary next-generation cloud platform."
- Write the product name as **Rostdav** in prose, **rostdav** (lowercase) in the wordmark and for commands and paths.
- No exclamation marks, no emoji in headlines, no superlatives.

Boilerplate (50 words): Rostdav is a free, open-source, self-hosted file server written in Rust. It is one small program with one data folder and works with the official Nextcloud apps over WebDAV. It offers versions, trash, shares, search and a web interface, runs on Linux (x86-64, arm64) and is licensed Apache-2.0 or MIT.

## Logo

Files: `rostdav-logo-light.svg`, `rostdav-logo-dark.svg` (lockup), `rostdav-mark.svg` (folder mark), `rostdav-mark-mono.svg`, `rostdav-app-icon.svg`, `favicon.svg`.

- The mark is an open folder with three sparks (data in motion). The wordmark is "rost" in Iron and "dav" in Rust; on dark backgrounds "dav" is Copper.
- Clear space: at least the height of the folder's tab on every side.
- Minimum size: mark 16 px, lockup 96 px wide.
- On a Rust background use the app icon (dark tile) or a single-colour wordmark; the mark's body would disappear. Marketing renders put `dav` in Iron there.
- Do not recolour outside the palette, stretch, outline, rotate, add shadows, or place the mark on busy photos.

Rust on Ivory and Ivory on Rust both pass 4.5:1 for large text; use Iron for small text on Rust. The web interface tokens live in `crates/rostdav-web/static/tokens.css` and are the source of truth.

## Typography

- **Space Grotesk** (400, 500, 700): headlines, wordmark, body. Headlines bold, letter-spacing -0.03 to -0.045 em, line-height about 1.0.
- **JetBrains Mono** (500): URLs, commands, version numbers, labels.
- Both are in `site/static/fonts/` under open licences (see `LICENSES.txt`).

## Layout

- Dark (Iron), light (Ivory) and Rust are the three canvases; alternate them in a carousel.
- One headline, at most one supporting sentence, URL in mono at the bottom.
- Generous margins (about 8 percent of the width). Faint grid and one Rust glow are the only background effects, on dark only.
